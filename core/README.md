# EXECUTIA Core

The Core defines the permanent beliefs and principles of EXECUTIA.

Everything else may evolve.  
The Core does not.

---

## What Core is

Core is the immutable foundation of the entire platform.

It is:

- permanent belief  
- product law  
- the source of truth for what EXECUTIA is for  

It is **not**:

- documentation of features  
- marketing copy for campaigns  
- website content  
- an implementation plan  
- a constitution for one product surface  

Governance documents, proofs, apps, and adapters implement Core.  
They do not redefine it.

## Repository rule

Every new feature proposal must reference Core.

If a proposal conflicts with Core, **the proposal must change**.  
Core never changes to justify a feature.

---

## Relationship to the rest of the repository

```
/core          Permanent beliefs (this directory)
/governance    Product constitutions and standards that apply Core
/proofs        Living demonstrations of Core in practice
/apps          Product surfaces (LIFE, ONE, GOV) — implementation
```

If every UI, feature, and adapter were deleted, Core would still define EXECUTIA completely.
