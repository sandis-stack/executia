# EXECUTIA Schemas

Canonical execution-object contracts shared across LIFE / ONE / GOV.

| Domain | Role |
|---|---|
| `invoice/` | Invoice object contract |
| `receipt/` | Receipt object contract |
| `payment/` | Payment object contract |
| `contract/` | Contract object contract |
| `shared/` | Shared types and common fields |

No premature fields. Schemas are defined when an Engine object requires a stable contract.
